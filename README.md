# UrbanBike AI

Interactive machine learning application for urban bike-sharing demand analysis and prediction using Seoul and Washington, D.C. bike-sharing data.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Community Cloud

Deploy `app.py` from this repository. The datasets are included in the repository and the Streamlit theme is configured under `.streamlit/config.toml`.
